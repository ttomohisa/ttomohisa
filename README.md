# Tomohisa

I work on cloud and data systems. Outside work, I make browser tools—often things I wanted to use myself.

I try to keep them simple: no accounts, no file uploads, and a single HTML file when it makes sense.

- [Single HTML Apps](https://github.com/ttomohisa/browser-kitty-apps) — Browser tools for PDFs, images, video, and data (Browser Kitty Apps).
- [WASM Zoo](https://github.com/ttomohisa/wasm-zoo) — Building native tools like FFmpeg and jq for WebAssembly.
