# Tomohisa

I work on cloud and data systems. In my spare time, I build browser tools and tinker with WebAssembly.

A lot of these projects start with something I needed myself. I prefer tools that run without an account or installation and process files locally. When it makes sense, I package the whole app into a single HTML file.

- **[Single HTML Apps](https://github.com/ttomohisa/browser-kitty-apps)** *(Browser Kitty Apps)* — Small utilities for PDFs, images, video, databases, and more. This repository keeps the app catalog, links to individual source repositories, and tracks release health.
- **[WASM Zoo](https://github.com/ttomohisa/wasm-zoo)** — WebAssembly builds of upstream tools including FFmpeg, ImageMagick, Ghostscript, and jq. It provides pinned build recipes, real-browser tests, and packages distributed through GitHub Releases and npm.
